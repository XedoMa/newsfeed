# About this project

## ABOUT ME
I'm a product manager in the GCC. I want a fun, visual reading experience, not a plain list of links. I'm not a developer, so explain each step briefly in plain language and ask before installing anything or pushing to GitHub.

## RULES
- Plain HTML, CSS, and JavaScript. No frameworks unless I ask.
- Keep the code simple and commented where it helps me understand it.
- Never commit secrets.
- Only display headlines, short snippets, and images with links back to the original article. Never copy full article text.
- When finished, summarize what you built, how to run it, and what to check.
